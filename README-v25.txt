A-1 FieldOps Mobile v25 — Branded Quote & Invoice Documents

New in v25:
- Professional A-1 estimate/quote template generated directly from existing FieldOps estimate, customer, job, and line-item records.
- Professional A-1 invoice template generated directly from invoice, customer, job, line-item, and payment records.
- One-tap View Quote / PDF and View Invoice / PDF from the existing review modals.
- Print / Save PDF uses the iPhone/browser native print sheet; no paid PDF service is required.
- Customer name, phone, email, service location, document number, issue date, status, scope, line items, subtotal, tax, total, payments, and balance are populated from FieldOps data.
- Invoice shows PAID when recorded successful payments cover the total.
- Draft documents are visibly stamped DRAFT.
- Estimate and invoice terms are included in the generated document.
- No prices, taxes, totals, customer data, or payment data are invented; missing values remain blank/unavailable.
- Existing AI Invoice Writer remains the place to clean the brief customer-facing description before generating the final document.

Recommended workflow:
Lead -> Customer/Job -> Estimate -> AI/Manual Scope -> View Quote/PDF -> Send/Approve -> Create Invoice -> AI Write Invoice -> View Invoice/PDF -> Send -> Record Payments -> Books/Tax export.
