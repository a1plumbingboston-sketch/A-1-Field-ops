A-1 FieldOps v15 — Money Today Foundation

Adds:
- Money Today command center on the main screen
- leads-to-chase count
- open estimate opportunity value
- unpaid invoice / collections value
- one-tap next-action buttons
- AI usage receipt after each AI estimate
- local AI request history (up to 200 requests) with timestamp, estimate, request ID and token usage

OPENAI_API_KEY remains server-side in Vercel. Keep the environment variable configured for Production.

This is the first automation-center foundation. Future builds can add timed follow-ups, customer messaging, review requests, scheduling and lead-source integrations.
